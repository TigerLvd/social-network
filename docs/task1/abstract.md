Необходимо написать интеграционные тесты контроллера авторизации (com.highload.architect.soc.network.api.LoginApiImpl, но с возможностью последующего расширения).

Ограничения:
1) использовать стек spring (не обязательно spring boot)
2) роботу с БД заменить на mock-и
3) не проверять скорость выполнения методов
4) не использовать асинхронную обработку, если это можно избежать
